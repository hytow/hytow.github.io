# 花果水果机 · 8090 复刻版

按 8090 街机「花果水果机」风格复刻的单机小游戏，纯前端实现，可加到手机主屏当独立应用（PWA）。

## 特点

- **零依赖、零构建**：只有 `index.html` + 图片 + 音效，不需要 npm、不需要编译。
- **纯单机**：无后端、无网络请求，全部逻辑跑在浏览器里。
- **移动端适配**：舞台固定 480×800 逻辑尺寸，按屏幕等比缩放；横竖屏均可。
- **PWA**：带 `manifest.json` 与图标，可「添加到主屏幕」全屏运行。

## 目录

```
fruit-slot-8090/
├── index.html       game 全部逻辑（HTML/CSS/JS 内联）
├── manifest.json    PWA 清单（名称、图标、竖屏、主题色）
├── favicon.ico
├── img/             143 张素材：图标、按钮、跑灯格子、水果、数字、背景
└── snd/             44 个音效（.mp3 / .ogg 双格式回退）
```

## 本地运行

请用 HTTP 服务打开，不要直接双击 `index.html`（`file://` 下 PWA 清单与部分音频会被浏览器拦截）：

```bash
cd fruit-slot-8090
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 部署

纯静态站点，推到 GitHub Pages / Cloudflare Pages / Vercel 均可，无需任何构建命令，根目录即发布目录。

> 说明：项目未注册 service worker，因此「添加到主屏幕」可用，但不保证完全离线运行；若需要离线，可自行补一个 sw 缓存 `img/`、`snd/`。
