# 听觉训练卡

给儿童做的听觉理解训练卡片：每张卡是一段小故事，配 4 个问题，家长/老师念故事，孩子听完回答问题。

## 特点

- **单文件应用**：`index.html` 内含全部 HTML / CSS / JS / 题库，零外部请求、零依赖，断网可用。
- **纯静态**：不需要后端、不需要构建工具、不需要 npm。
- **移动端优先**：最大宽度 560px 居中，适配手机竖屏与桌面浏览器。

## 使用

双击 `index.html` 即可打开；若要用本地服务器：

```bash
python -m http.server 8080
# 访问 http://localhost:8080
```

## 功能

- 按难度筛选：全部 / ★ / ★★ / ★★★
- 下拉框直接跳转到任意一张卡
- 点问题展开答案
- 每题停留时间可设 20 / 30 / 45 / 60 秒
- 答题模式带计时与结果反馈

## 修改题库

题库以 JavaScript 数组的形式存放在 `index.html` 的 `<script>` 内，每条记录含故事文本、等级与四组「问题—答案」，按现有字段格式追加即可。

## 部署

纯静态，可直接托管在 GitHub Pages、Cloudflare Pages、Vercel 或任意静态服务器上。
